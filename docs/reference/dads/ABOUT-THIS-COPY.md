## なぜリポジトリに置いているか

配布元の `README.md` にあるとおり、この zip は「主にAI参照用途としてMarkdown形式へ変換したもの」で、
そのまま参照されることを想定した配布物です。要約して置き換えると情報が落ち、
しかも落ちたことが読み手から見えなくなるため、原文をそのまま持つ形にしています。

## 収録範囲

zip 全体（125ファイル・735KB）のうち、次の3つを複製しています。

| ディレクトリ | 内容 |
| --- | --- |
| `foundations/` | 基本デザイン8領域（カラー、タイポグラフィ、アイコン、レイアウト、リンクテキスト、余白、角の形状、エレベーション） |

必要になったら同じ zip から `components/` を追加してください。

その結果、次の3箇所のリンクだけが手元では解決しません。リンク先は公式サイトで参照してください。

## 利用条件

`introduction/notices/index.md` に記載されています。要点は、コンテンツを利用する際に出典を記載すること、
編集・加工して利用する場合はその旨を出典とは別に記載すること、
加工した情報をデジタル庁が作成したかのような態様で公表しないことです。

**Small Step 側にこの内容の要約はありません。**
