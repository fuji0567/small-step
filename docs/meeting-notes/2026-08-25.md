# 2026-08-25 開発議事録

## 目的

小規模な保育連絡サービス「Small Step」のバックエンドを、まずMac内だけで動かす方針で進めた。保護者へのLINE連絡、音声からの記録候補作成、MCP連携の基盤を作る。

## 本日の決定

- レンタルサーバーやGPUクラウドはまだ契約せず、Mac内のローカル構成で開発を続ける。
- LLMはOllamaの `qwen3:4b` をMac内で実行する。さくらの高火力は、本番負荷や性能要件が見えてから検討する。
- 音声の原本と文字起こし全文はFastAPIのデータベースへ保存しない。音声は処理後に自動削除する。
- 音声から作成されるのは先生確認用の `pending_review` 候補であり、承認前にLINE送信しない。

## 完了したこと

- GitHubリポジトリ `fuji0567/small-step` への初回プッシュを完了した。
- FastAPIの園・先生・園児・記録・承認・通知のバックエンド基盤を作成した。
- LINE Messaging APIのWebhookを接続し、招待コードで保護者LINEアカウントと園児を結び付けた。
- テスト通知をLINEへ実送信して動作確認した。
- Edge端末用APIキーの発行・ローテーション・安全な確認スクリプトを追加した。
- Notion同期の基盤コードとデータベース作成スクリプトを追加した。
- MacにOllamaと `qwen3:4b` を導入し、Apple M3のMetal GPUでローカル推論できることを確認した。
- `faster-whisper` をプロジェクト専用のPython環境へ導入した。
- 音声をローカル受け取りフォルダだけから読む処理、文字起こし、匿名化候補の生成、FastAPIへの候補登録処理を実装した。
- MCPサーバーを `127.0.0.1:8002` のローカル限定で起動し、状態確認・音声分析・候補登録の3ツールを公開した。
- 合成音声を使い、MCP経由で音声分析まで動作確認した。元のWAVが処理後に削除されることを確認した。
- LLMが英語や入力にない内容を返すケースを見つけ、日本語固定・入力根拠の制約・技術テスト時の固定出力・推論無効化を追加した。
- 自動テストは `13 passed`。`git diff --check` も成功した。
